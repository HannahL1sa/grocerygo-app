# 🛒 Grocery Go
Grocery Go is a full-stack web application designed to simplify grocery shopping by providing users with a convenient platform to browse groceries, manage their shopping, and access essential features through secure user authentication. The application helps users keep track of the items they need to purchase, making grocery shopping more organized and convenient.

## ✨ Features
- **User Authentication:** Secure user registration and login.
- **Grocery List Management:** Create and manage personalized grocery lists.
- **Item Organization:** Keep track of grocery items needed for shopping.
- **Database Integration:** Store user information and grocery lists in MongoDB.
- **Responsive Design:** Designed to provide a user-friendly experience across different screen sizes.

## 🛠️ Tech Stack
* **Frontend:** Next.js, TypeScript, Tailwind CSS
* **Backend:** Next.js API Routes, Node.js
* **Database:** MongoDB
* **Authentication:** Auth.js (NextAuth.js), bcrypt
